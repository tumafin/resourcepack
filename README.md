# TUMAFIN Resource Pack

Официальный набор ресурсов сервера **TUMAFIN** для Minecraft Java Edition.
Содержит текстуры, используемые на сервере.

![Minecraft](https://img.shields.io/badge/Minecraft-26.2–26.3-green)
![pack_format](https://img.shields.io/badge/pack__format-88–97-blue)

## 📦 Установка

### Вариант 1 — автоматически (рекомендуется)

При входе на сервер Minecraft сам предложит скачать набор ресурсов
(если включена опция «Наборы ресурсов: Запрашивать / Включены»).
Согласитесь — и набор установится автоматически.

### Вариант 2 — вручную

1. Скачайте набор ресурсов `tumafin_resourcepack.zip` из раздела
   [GitHub Releases](https://github.com/tumafin/resourcepack/releases).
2. Поместите его в каталог `resourcepacks` вашего клиента Minecraft
   (`.minecraft/resourcepacks`).
3. Включите набор в игре: `Настройки → Наборы ресурсов` и переместите
   его вверх списка (набор должен иметь высокий приоритет).

> ⚠️ Используйте ту версию набора, которая соответствует текущей версии
> сервера. При обновлении сервера скачивайте новый релиз.
