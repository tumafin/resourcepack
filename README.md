# TUMAFIN Resource Pack

## 📋 Параметры пакета

| Параметр | Значение |
| --- | --- |
| `pack_format` | `97` (26.3) |
| `min_format` ... `max_format` | `88` ... `97` (26.2 — 26.3) |

## 📦 Установка

1. Скачайте архив набора ресурсов.
2. Поместите его в каталог `resourcepacks` вашего клиента Minecraft
   (`.minecraft/resourcepacks`).
3. Включите набор в игре: Настройки → Наборы ресурсов и переместите его вверх списка
   (набор должен иметь высокий приоритет).
